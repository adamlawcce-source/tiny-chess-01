A 4 KB chess engine in Python (0x88 board, alpha-beta search with a 9-second clock and a king-shelter eval term). Trial Elo 1451 on the local gauntlet — above the 1360 gate, zero losses on time.

## Run it

```sh
python3 -c "import main as E; E.st('4k3/8/8/8/8/8/8/4K3 w - - 0 1'); print(E.ev())"
```
